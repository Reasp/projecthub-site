# projecthub-site

Public website of [ProjectHub](https://github.com/Reasp/ProjectHub), the Agentic Development Environment: a control room for AI coding agents.

**English** · [Русский](README.ru.md)

## Layout

- `content/product/` — product context exported from the ProjectHub source repository (README, editions, decisions, screenshots, pitch, `product.json`). Generated by `scripts/site/export-product-context.mjs` in the source; do not edit by hand.
- `backlog/` — tasks, documentation and architecture decisions of the site itself (Backlog.md, in Russian).
- `.projecthub/infra/` — ProjectHub infrastructure for agents (documentation search, process tools); not part of the website build.
- `CLAUDE.md`, `AGENTS.md`, `GEMINI.md`, `.agents/rules/` — rules for AI agents working on the site.

The website is built with Astro and Starlight (see `backlog/decisions/decision-1`): marketing pages in `src/pages/` and `src/pages-shared/`, documentation in `src/content/docs/`, interface strings in `src/i18n/`.

```bash
npm install
npm run dev       # http://localhost:4321
npm run build     # static output in dist/
npm run preview   # serve dist/ locally
```

Deployment: Cloudflare Pages builds `main` on every push and gives every other branch a preview URL; the setup steps for the owner are in `backlog/docs/doc-2`.

## Working with the source repository

This repository is a git submodule `site/` of the ProjectHub source. Clone the source with submodules:

```bash
git clone --recurse-submodules git@github.com:Reasp/ProjectHub.git
```

Site work happens in this repository, not in a worktree of the source. Product context is refreshed from the source with:

```bash
npm run site:export   # in the ProjectHub source
```

## Languages

The base language of the site is English; every page also has a Russian version under `/ru/`.
