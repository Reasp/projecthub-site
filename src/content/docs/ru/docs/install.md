Сборки открытой редакции (Personal) перечислены на странице [Скачать](/ru/download/) с размерами файлов и контрольными суммами SHA-256. Все выпуски также есть на странице релизов публичного репозитория `projecthub-oss` на GitHub.

## Что нужно, кроме ProjectHub

- **Git.** ProjectHub работает с Git-репозиториями и создаёт Git worktree для каждого агента.
- **Хотя бы один агент или модель**, например:
  - Claude Code CLI (`claude`), вход в ваш аккаунт выполнен. API-ключ в этом случае не нужен.
  - Codex CLI (`codex`).
  - API-ключ провайдера: Anthropic, OpenRouter, DeepSeek или любого OpenAI-совместимого адреса.
  - Локальные модели через Ollama.

Аккаунты, ключи и серверы моделей добавляются в окне **Подключения** ProjectHub.

## Windows

Для Windows x64 публикуются два файла:

| Файл | Что это | Обновления |
|---|---|---|
| `ProjectHub-Setup-<версия>.exe` | Установщик (NSIS) | Автоматически |
| `ProjectHub-<версия>.exe` | Portable-сборка, работает без установки | Вручную: скачать новый файл |

Чтобы установить:

1. Скачайте установщик или portable-файл со страницы [Скачать](/ru/download/).
2. Запустите файл.
3. Сборки пока не подписаны, поэтому Windows SmartScreen может предупредить о неизвестном издателе. Чтобы продолжить, выберите **Подробнее**, затем **Выполнить в любом случае**.

При первом включении Remote Control Windows может спросить, можно ли ProjectHub работать с сетью. Разрешите доступ для **частных сетей**.

## macOS

Сборки для Apple silicon (arm64) и Intel (x64) публикуются в форматах `.dmg` и `.zip`.

1. Скачайте файл для своего Mac со страницы [Скачать](/ru/download/).
2. Откройте `.dmg` и перетащите ProjectHub в **Программы** или распакуйте `.zip`.
3. Запустите ProjectHub.

Сборка для macOS не подписана сертификатом Apple Developer ID и не нотаризована, поэтому macOS блокирует первый запуск. Чтобы открыть приложение:

1. Попробуйте открыть ProjectHub один раз и закройте предупреждение.
2. Откройте **Системные настройки → Конфиденциальность и безопасность**.
3. Рядом с сообщением о ProjectHub выберите **Всё равно открыть** и подтвердите.

В более старых версиях macOS можно также щёлкнуть ProjectHub в **Программах** с нажатой клавишей Control, выбрать **Открыть** и подтвердить.

Другие особенности macOS:

- Обновления не устанавливаются автоматически. Когда выходит новая версия, ProjectHub показывает ссылку на релиз; скачайте и замените приложение сами.
- macOS может запросить доступ к **локальной сети**. Разрешите его, если пользуетесь Remote Control или соединяете несколько компьютеров в локальной сети.

## Linux

Для Linux публикуется AppImage для x64.

1. Скачайте `ProjectHub-<версия>.AppImage` со страницы [Скачать](/ru/download/).
2. Сделайте файл исполняемым: `chmod +x ProjectHub-<версия>.AppImage`.
3. Запустите файл.

AppImage обновляется автоматически.

## Обновления

ProjectHub проверяет обновления при запуске и по запросу: откройте **Диагностику** и нажмите **Проверить обновления**. Кроме самого запроса об обновлении, ничего не отправляется.

| Сборка | Как обновляется |
|---|---|
| Установщик Windows | Скачивает обновление; **Перезапустить и установить** применяет его |
| Portable для Windows | Новый файл скачивается вручную |
| macOS | Ссылка на релиз; приложение заменяется вручную |
| AppImage для Linux | Автоматически |

## Мобильный клиент

Мобильный клиент — это пульт к ProjectHub на вашем компьютере: агенты, задачи, процессы и одобрения работают на компьютере, телефон показывает их и управляет ими. Сопряжение описано в разделе [Remote Control](/ru/docs/remote-control/).

Пользоваться им можно двумя способами:

- **Клиент в браузере.** Его раздаёт само десктопное приложение. Откройте ссылку сопряжения или отсканируйте QR-код из окна Remote Control. Клиент в браузере шифрует трафик и работает только по HTTPS, поэтому сначала запустите встроенный туннель (см. [Remote Control](/ru/docs/remote-control/#клиент-в-браузере)).
- **Приложение для Android.** APK пока не публикуется на странице «Скачать»: он подписан только отладочным ключом. Публикация в магазинах приложений запланирована.

Если вы получили APK для Android:

1. Откройте файл APK на телефоне. Android попросит разрешить установку из этого источника — разрешите для приложения, через которое открываете файл.
2. Google Play Protect может предупредить о неизвестном разработчике из-за отладочной подписи. Выберите установку всё равно.

## Сборка из исходников

Открытую редакцию можно собрать из публичного репозитория `projecthub-oss` (нужны Node.js 22 и Git):

```bash
git clone https://github.com/Reasp/projecthub-oss.git
cd projecthub-oss
npm install
node scripts/build-info.mjs
npm run build:open                     # десктопное приложение без платных модулей
npm run build:mobile                   # необязательно: веб-клиент для телефонов, его раздаёт десктоп
npx electron-builder --win portable    # Windows: release/*.exe
npx electron-builder --mac dmg         # macOS (без подписи)
npx electron-builder --linux AppImage  # Linux
```
