ProjectHub — Agentic Development Environment (ADE): десктопное приложение, в котором ИИ-агенты для разработки берут задачи, работают параллельно и спрашивают человека перед рискованными шагами.

## Как устроен ProjectHub

- **Единица работы — задача.** Задачи — это Markdown-файлы в папке `backlog/` проекта (формат Backlog.md). Вы пишете задачу с критериями приёмки и отдаёте её агенту.
- **Каждый агент работает в своём Git worktree.** Несколько агентов могут одновременно работать над одним репозиторием, не трогая файлы друг друга и вашу рабочую копию.
- **Рискованные шаги ждут одобрения.** Команды, запись файлов и другие действия, которые не разрешены правилами, приходят запросами. Вы одобряете или отклоняете их на компьютере, на телефоне или в Telegram.
- **«Готово» проверяет ProjectHub, а не заявляет агент.** В цикле «До готовности» ProjectHub запускает проверки проекта и сверяет каждый критерий приёмки с доказательствами агента.
- **Любой агент и любая модель.** Claude Code, Codex, Antigravity, API-провайдеры (Anthropic, OpenRouter, DeepSeek, любой OpenAI-совместимый адрес) и локальные модели через Ollama.
- **Local-first.** Состояние хранится на вашем диске. Телеметрии нет; логи и дампы падений остаются на вашем компьютере.

Десктопное приложение работает в Windows, macOS и Linux. Мобильный клиент позволяет следить за агентами и одобрять их шаги с телефона.
