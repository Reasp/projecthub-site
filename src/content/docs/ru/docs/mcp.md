ProjectHub запускает собственный MCP-сервер (Model Context Protocol). Агенты с поддержкой MCP — Claude Code, Cursor, Windsurf, Antigravity — читают и обновляют через него задачи, документы и память проекта, а с основным токеном управляют и самим ProjectHub.

## Адреса

Сервер слушает только `127.0.0.1`, порт `42042`. С других компьютеров он недоступен; удалённый доступ идёт через [Remote Control](/ru/docs/remote-control/).

| Транспорт | Адрес |
|---|---|
| SSE | `http://127.0.0.1:42042/sse` |
| Streamable HTTP | `http://127.0.0.1:42042/mcp` |

Каждый запрос должен нести заголовок `Authorization: Bearer <токен>`. Запросы со страниц сайтов (с заголовком `Origin`) отклоняются.

Индикатор **MCP** в строке состояния открывает окно **Встроенный MCP HTTP/SSE Сервер**. В нём видны адрес, токен и готовая конфигурация для копирования (**Копировать JSON**, **Копировать cURL**), там же сервер запускается и останавливается.

## Два вида токенов

### Токен агента проекта

Это токен для агентов, которые работают над проектом.

- Терминал зарегистрированного проекта сам получает две переменные окружения: `PROJECTHUB_MCP_URL` и `PROJECTHUB_AGENT_TOKEN`. Агенты, запущенные в этом терминале, пользуются ими.
- Токен привязан к одному проекту. С ним сервер даёт только инструменты задач, документов, поиска и памяти этого проекта и пишет только в его папку `backlog/`. Каждое изменение записывается в журнал аудита.
- Одобрения, процессы и управление окном для этого токена закрыты.

| Инструменты | Что делают |
|---|---|
| `task_list`, `task_view`, `task_create`, `task_update` | Чтение, создание и изменение задач |
| `doc_list`, `doc_view`, `doc_create`, `doc_update` | Чтение, создание и изменение документов |
| `docs_search` | Поиск по документации проекта |
| `memory_write`, `memory_search`, `memory_delete` | Запись, поиск и удаление фактов памяти проекта |

В таблице основные инструменты, список не полный: например, есть ещё инструменты `doc_branch_*` для веток документации. Полный список показывает ваш MCP-клиент при подключении.

Задачи, которые завёл агент, помечаются как заведённые агентом. Пока вы их не подтвердите, они не запускаются автоматически.

### Основной токен

Токен из окна MCP (**Сессионный токен доступа**) даёт полное управление: переключение проектов и вкладок, отправку промптов в Agents Studio, управление процессами, чтение задач и решения по запросам одобрения.

- Он создаётся один раз и хранится, пока вы не перевыпустите его кнопкой **Обновить**, поэтому внешние конфигурации не ломаются после перезапуска.
- Не кладите его в окружение агента и в файлы проекта: им можно одобрить запросы, которые адресованы вам.

## Конфигурация в проекте

Инициализация проекта (см. [Первые шаги](/ru/docs/quick-start/#2-инициализируйте-проект)) добавляет в `.mcp.json` такую запись:

```json
{
  "mcpServers": {
    "projecthub": {
      "type": "sse",
      "url": "${PROJECTHUB_MCP_URL:-http://127.0.0.1:42042/sse}",
      "headers": { "Authorization": "Bearer ${PROJECTHUB_AGENT_TOKEN:-}" }
    }
  }
}
```

Сам токен никогда не пишется в файлы проекта: он приходит из окружения терминала ProjectHub. Пустые значения по умолчанию позволяют Claude Code запуститься в этом проекте и вне ProjectHub.

Для Antigravity запись попадает в `.agents/mcp_config.json` и использует адрес Streamable HTTP:

```json
{
  "mcpServers": {
    "projecthub": {
      "serverUrl": "http://127.0.0.1:42042/mcp",
      "headers": { "Authorization": "Bearer ${env:PROJECTHUB_AGENT_TOKEN}" }
    }
  }
}
```

## Ограничения

- Инструменты доступны, только пока запущен ProjectHub. Без него у агентов остаются правила проекта и файлы в `backlog/`, но не инструменты MCP.
- Сервер локальный. Участники команды на других компьютерах к нему не подключаются.
