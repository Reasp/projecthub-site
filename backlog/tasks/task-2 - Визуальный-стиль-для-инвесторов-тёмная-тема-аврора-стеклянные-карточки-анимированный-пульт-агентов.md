## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
### Исполнитель

Агент в репозитории сайта.

### Почему

Владелец: «Надо красивее сделать. Люди сейчас любят эффекты. Обычным пользователям будет пофигу, а вот инвесторам надо видеть красоту». Каркас TASK-1 функционален, но визуально нейтрален.

### Цель

- Тёмная тема по умолчанию (светлая остаётся по prefers-color-scheme и переключателю), аврора-градиенты в hero, стеклянные карточки с подсветкой при наведении, градиентные заголовки.
- Анимированный макет «пульта управления»: задача, три агента с прогрессом и статусами, карточка одобрения, проверки, слияние — чистый CSS, подпись «иллюстрация».
- Схема процесса в пять шагов, полоса цифр из питча (content/product/pitch/linkedin-post-en.txt) с пометкой даты.
- Pricing и Compare в том же стиле; Team выделена как «в пилотах».

### Ограничения

- Без внешних скриптов, шрифтов и библиотек (CSP public/_headers), страницы открываются без JavaScript, анимации отключаются при prefers-reduced-motion.
- Тексты только через словари en/ru; факты только из content/product/.
- Проверка снимками на телефоне и десктопе в обеих локалях.

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
### Что сделано (2026-10-22)

- ADR [[decision-2]]: тёмная тема по умолчанию (светлая по prefers-color-scheme и переключателю), эффекты только на CSS, схемы инлайн-SVG, без внешних ресурсов; scroll-driven появление отвергнуто (прячет контент в полноразмерных снимках).
- Главная: аврора-градиенты в hero, градиентный заголовок, бейдж «Open source · MIT · local-first», анимированный макет пульта (`src/components/ControlRoom.astro`: задача с критериями, три агента с прогрессом и статусами, карточка одобрения; подпись «иллюстрация»), стеклянные карточки отличий с иконками, схема процесса в пять шагов, три схемы Personal / Team / Enterprise (`src/components/Scenarios.astro`, инлайн-SVG по данным словаря, на телефоне — горизонтальная прокрутка), блок цифр из питча (`content/product/pitch/linkedin-post-en.txt`, с пометкой даты), демо-плейсхолдер в стиле видеокадра, карточка поддержки.
- Переключатель языка: иконка-глобус с кодом текущего языка, по клику выпадающий список языков на `<details>` (работает без JavaScript), текущий язык отмечен.
- Поддержка проекта: страница `/support/` и `/ru/support/` (на что идут деньги, другие способы помочь), пункт «Support ♥» в навигации, ссылка в подвале, карточка-просьба на Download и на главной. Ссылка для пожертвований — `links.donate` в `product.json` (экспорт источника); пока `null`, кнопка ведёт на страницу поддержки с честной подписью. В источнике заведена TASK-144.6 на кнопку поддержки в бесплатной редакции приложения.
- Приватный репозиторий: `links.sourceRepository` в `product.json` теперь `null` (источник приватный, публичное зеркало — TASK-144.5 источника); ссылки GitHub в навигации, подвале и Starlight показываются только при заполненной ссылке; блок «сборка из исходников» и фраза «откройте issue» убраны, вместо них — «публичное зеркало появится с первым выпуском».
- Pricing: карточка Team выделена градиентной рамкой; Compare: отметки ✓, подсветка строк.
- Проверка: сборка 28 страниц; снимки с выключенным JavaScript в `.playwright-mcp/` — Home, Pricing, Compare, Support, Download, Docs на 390 и 1366 px в en и ru, тёмная и светлая темы, крупные планы схем, макета и открытого меню языка; горизонтального скролла нет на всех страницах.
