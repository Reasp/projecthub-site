## Context

Каркас сайта ([[TASK-1]], [[decision-1]]) был функционален, но визуально нейтрален. Владелец (2026-10-22): «Люди
сейчас любят эффекты. Обычным пользователям будет пофигу, а вот инвесторам надо видеть красоту». При этом
ограничения сайта не меняются: страницы открываются без JavaScript, внешних скриптов, шрифтов и аналитики нет
(`public/_headers` отдаёт CSP только на свой origin), факты — только из `content/product/`.

Рассмотрено:

1. **Библиотеки анимаций (GSAP, Framer Motion, Lottie) и веб-шрифты с CDN.** Нарушают CSP и правило «без внешних
   ресурсов»; без JavaScript эффектов нет вовсе.
2. **Картинки-рендеры схем (PNG из генератора изображений).** Не локализуются (текст внутри картинки), не
   масштабируются на телефон, тяжёлые; каждое изменение фактов требует перерисовки.
3. **Scroll-driven animations (`animation-timeline: view()`) для появления секций.** Проверено: в полноразмерных
   снимках и в режиме чтения секции остаются невидимыми (контент ниже окна «не вошёл» в область просмотра).
   Отвергнуто.
4. **Чистый CSS + инлайн-SVG** — принято.

## Decision

1. **Тёмная тема по умолчанию**, светлая — по `prefers-color-scheme: light` или переключателю (`data-theme` на
   `<html>`). Оба набора цветов — переменные в `src/styles/global.css`; акценты синий / фиолетовый / бирюзовый.
2. **Эффекты только на CSS:** аврора-градиенты в hero (`::before`/`::after` с `blur` и медленным `drift`),
   стеклянные карточки (`backdrop-filter`) с градиентной рамкой при наведении, градиентные заголовки,
   свечения кнопок. Всё отключается `prefers-reduced-motion: reduce`. Scroll-driven появление не используется.
3. **Анимированный макет пульта** (`src/components/ControlRoom.astro`): задача с критериями, три агента с
   прогрессом и статусами, карточка одобрения — CSS-keyframes, подпись «иллюстрация», `aria-hidden`. Тексты из
   словарей.
4. **Схемы Personal / Team / Enterprise** (`src/components/Scenarios.astro`): инлайн-SVG по данным узлов и рёбер,
   подписи из словарей, геометрия общая для локалей; узлы «hero» с градиентом, «dash» — пунктирные области,
   пунктирные рёбра — вспомогательные связи. На узких экранах SVG прокручивается горизонтально, как таблицы.
5. **Шрифты системные**, иконки — короткие инлайн-SVG внутри компонентов. Внешних ресурсов нет.
6. **Переключатель языка** — иконка-глобус с кодом целевого языка (`EN`/`RU`), ссылка на ту же страницу другой
   локали; без JavaScript работает как обычная ссылка.
7. **Пожертвования:** страница `/donate/` и `/ru/donate/`, пункт «Donate ♥» («Пожертвовать ♥») в навигации, ссылка в
   подвале и карточка-просьба на странице Download и на главной (до 2026-10-23 — «Support», `/support/`; владелец
   попросил прямое «Donate»). Ссылка — `links.donate` в `content/product/product.json` (сейчас GitHub Sponsors
   владельца, задаётся экспортом источника); без неё кнопка ведёт на страницу пожертвований с честной подписью.
   Просьба мягкая: без модальных окон и баннеров.
8. **Ссылок на приватный репозиторий-источник нет.** `links.sourceRepository` в `product.json` пустая, пока не
   появится публичное зеркало открытой редакции; пункт GitHub в навигации, подвале и Starlight показывается
   только при заполненной ссылке.
9. **Платные редакции до выпуска — серые со штампом** ([[TASK-3]], просьба владельца 2026-10-27). Карточки Team и
   Enterprise на Pricing и на главной: пунктирная рамка, содержимое обесцвечено, поверх цветной штамп. Текст штампа
   честный по статусу из doc-12: Team — «In development» / «В разработке» (модули `ee/` пишутся), Enterprise —
   «Planned» / «Запланировано» (работы не начаты). Когда редакция выйдет, класс `wip` и штамп снимаются.
10. **Дорожная карта — отдельная страница `/roadmap/`** ([[TASK-3]]): шкала двенадцати месяцев с отметкой «мы здесь»,
    три крупные вехи из питча (месяцы 0–3, 3–6, 6–12) с критерием «готово» и статусом Now / Next / Later, блок
    «уже сделано» по фактам (`releases.json`), дорожка раундов Pre-seed → Seed → Series A. Вехи закрываются
    критериями, а не датами: календарных дат и сумм раундов на сайте нет, их нет и в источнике фактов. Стили — в
    отдельном `src/styles/roadmap.css`.

## Consequences

- Плюсы: заметный, современный вид без единого внешнего запроса; локализуемые схемы; всё читается без JS.
- Минусы: `backdrop-filter` и `color-mix()` требуют современных браузеров (2023+), в старых — плоские карточки без
  размытия; анимированный макет — иллюстрация, не экран продукта, что подписано явно.
- Долг: демо-видео и реальные скриншоты экранов продукта для hero — после задачи демо в источнике; ссылка для
  пожертвований — за владельцем.
- Реализация — [[TASK-2]].
