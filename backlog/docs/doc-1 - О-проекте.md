# projecthub-site

## Назначение

Публичный сайт ProjectHub — Agentic Development Environment, «control room for AI coding agents». Сайт
показывает продукт миру: тезис, установка, загрузки, цены по редакциям, честное сравнение с конкурентами,
пользовательская документация. Рынок мировой, базовый язык английский, у каждой страницы есть русская версия.

Это отдельный публичный репозиторий, подключённый сабмодулем `site/` к репозиторию-источнику ProjectHub
(decision-158 источника, п. 7–8). Сайт собирается без доступа к источнику: продуктовый контекст лежит в
`content/product/` и обновляется экспортом из источника.

## Стек

Статический генератор выбирается в задаче каркаса сайта и фиксируется решением в `backlog/decisions/`.

## Структура

- `content/product/` — экспорт из источника: README на двух языках, `doc-12.md` (редакции),
  `decision-85/86/123/158/159.md`, `assets/` (скриншоты), `pitch/`, `product.json`. Руками не править.
- `backlog/` — задачи, документы, решения и память сайта.
- `.projecthub/infra/` — инфраструктура ProjectHub для агентов: поиск по документации (`docs-rag`),
  процессы (`env-tools`), Backlog.md MCP, Playwright MCP. Команды `npm run …` инфраструктуры выполняются в
  этом каталоге.
- `.mcp.json`, `.agents/mcp_config.json` — MCP-серверы для Claude Code и Antigravity, включая `projecthub`.

## Где что искать

- Задачи — `backlog/tasks/`
- Архитектурные решения — `backlog/decisions/`
- Память проекта — `backlog/memory/`
- Правила сайта (продукт, редакции, язык, источник фактов) — раздел «Сайт ProjectHub» в `CLAUDE.md`
